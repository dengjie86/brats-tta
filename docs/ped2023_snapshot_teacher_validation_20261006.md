## 方法与依据

[Snapshot Ensembles](https://arxiv.org/abs/1704.00109)展示训练轨迹上的模型集成，但依赖循环学习率获得多样性；当前普通训练的晚期checkpoint不保证独立或跨极小值，不能称原版复现。[Self-ensemble for test time adaptation](https://doi.org/10.1016/j.neucom.2025.131038)研究内部多分类器与小模型集成；本轮借鉴检验不同模型假设的思路，不宣称创新或效果保证。

同既有12开发ID，完整体积，原生IN四分类Dice+CE、128³/.5/Gaussian/8镜像。复用经过核验的250原方向概率，首例补推250逐值相同。固定175/200/225，不按PED成绩挑epoch。各模型实际加载并核对状态，使用原生底层完整滑窗避免高层接口重载250。

三旧快照同类、各maxP≥0.8且margin≥0.2时自动接受平均软概率类别，否则沿用250硬标签。四类对称，无WT/ET固定。保存旧三者融合、四者融合、三个单epoch诊断，以及自动教师和两个逐病例/有向类别/数量匹配的源概率与随机对照。所有输出固定后再读取本次GT评价。
