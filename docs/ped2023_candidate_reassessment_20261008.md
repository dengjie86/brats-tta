## 3. 机制故事应怎样组织

建议主线：**病灶局部保留的背景上下文探测，结合多观察共识进行病例自适应纠错；可进一步用少量IN参数将修正传播到原图预测。**

1. **问题假设。** 成人到儿童的外观、解剖及上下文分布变化，可能改变网络对内部组织的判断。当前模型存在大量高置信NC→ED错误，简单熵最小化不能独立提供纠错方向。这里是由观察提出的假设，不宣称已经识别唯一域偏移根因。
2. **理论动机。** IN按每个样本、每个通道的空间特征计算均值方差；每个patch的远处背景可以通过归一化统计及感受野影响局部输出，即使病灶附近的输入值保持不变。[PyTorch InstanceNorm3d定义](https://docs.pytorch.org/docs/2.11/generated/torch.nn.InstanceNorm3d.html)。IN在图像风格处理中的作用已有文献，但不是本任务有效性的直接证明。[Ulyanov等](https://arxiv.org/abs/1607.08022)。
3. **具体操作。** 保留Source WT及10mm邻域、10–20mm平滑过渡，在远处分别做均值方差匹配的模糊和中位数中性化；原零背景保留。两观察在保留区给出一致且符合固定置信条件的类别时形成修正，其余保留Source。四类可改变，没有固定WT/ET或仅ED→NC输出。
4. **学习扩展。** 每例重置，仅更新22层IN的7680个affine标量。学习上下文给出的相对log-odds修正，同时以原图Source为软锚点，保持native推断方式一致。这个设计有实测收益，但当前不主张聚合后目标显著优于逐视图目标，也不主张Fisher是必要创新。
5. **实验证据。** 直接teacher在99例有Source相对收益；12例统计交换说明归一化敏感性参与了响应，但不能量化为某百分比的因果解释。修改量审计显示病例专属预算优于同总量统一分配，支持病例自适应纠错程度具有信息。轻量适应在两组都有NC/TC增益，仍有边界折中。

这条故事不宜写成“已识别儿童NC的新生物学特征”或“已证明成人背景导致错误”。更合适的贡献定位是**利用当前病例的上下文响应估计纠错方向和程度**。精细体素语义辨别的优势仍有限；已有几何对照几乎重现TC涨幅，需要保留这一发现。

## 4. 强对照如何帮助解释贡献

几何对照借用了teacher逐病例、逐类别方向的修改数量，并非一个独立估计修改量的部署算法。因此TC接近不等于整个上下文方法没有作用，更可能提示收益主要体现在“这例该改多少”，而非独特的精细选点。

已有去重98组的预算审计：自身数量+固定几何TC54.3665%，同总量统一比例53.3978%；原12以外86组分别53.5213%与52.2680%。真实ED误改量也更少。该事后对照支持保留病例响应这条解释，但仍是开发数据中的关联证据，不能冒充独立泛化或正式p值。
