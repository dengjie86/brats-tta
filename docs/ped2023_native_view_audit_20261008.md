2026-10-08。复用12个开发ID的Source、full（旧extent）和without_delete状态，完成1,920次只读native网络前向。36个完整概率数组全部逐值重现旧结果。**证据不支持把本轮主要WT损伤归因于前景类别分歧后的融合，或FP16累加舍入。** 大量位置在融合前的native视图中已经改变了前景判断。

根目录：`D:/Workspace/deeplearn/3dunet/outputs/ped2023_native_view_audit_20261008`，仅本地保存、被Git忽略。前序见[删除监督消融](ped2023_deletion_ablation_20261008.md)。本轮没有训练、新候选mask或性能增益；所有99例PED已经参与开发，不能称独立测试。

## 记录方式与范围

从同一源checkpoint及已保存的绝对IN affine值精确重建三个状态；每次前后核对state SHA。native预处理、128³、.5滑窗、Gaussian、八镜像及上游FP16运算顺序不变。forward hook只读输出，按照实际镜像顺序还原坐标；wrapper记录native镜像平均的patch logits，返回原tensor。没有替换平均公式、修改输出或跨病例状态。

记录位置为既有teacher/full/without_delete相对Source类别变化的并集，共89,137个池化体素。它不使用GT，覆盖本轮研究的全部新增错误和纠正，但不包括并集之外未变化的源错误。每个位置保存：

- 各native patch与镜像组合的四类argmax票数；
- 每个patch完成八镜像平均后的四类票数；
- 按native Gaussian与等权镜像计算的类别支持；
- 各视图WT gap、最终gap及“全部视图前景但融合为背景”的位置数；
- 保持相同FP16网络输出、仅将两个融合阶段或滑窗阶段改为FP64计算的影子类别。

影子计算用于诊断累加算术，不代表网络改成FP64；没有生成其新mask或评价其全体积Dice。所有记录固定之后才读取GT。以错误位置为条件分析可能夸大某个反事实的好处，不能据此宣称新推断规则有效。

## 编辑域外WT错误的native支持

下表的支持率是先按位置计算Gaussian加权前景票数，再对该组体素求平均，不是病例平均正确率。混合支持代表不同视图投票有分歧。

| 状态与位置 | 体素数 | 所有raw视图FG / 混合 / 全BG | Source加权FG支持 | 适应后加权FG支持 |
|---|---:|---|---:|---:|
| full误删真实WT | 9,548 | 0 / 8,887 / 661 | 75.67% | 32.49% |
| full新增假WT | 3,945 | 84 / 3,861 / 0 | 27.28% | 70.35% |
| without_delete误删真实WT | 2,010 | 4 / 1,980 / 26 | 65.31% | 46.10% |
| without_delete新增假WT | 7,271 | 44 / 7,227 / 0 | 36.59% | 64.72% |

full的9,548个误删位置，没有一个在所有raw native视图都为FG，也没有一个在所有镜像平均patch中都为FG。只有6个位置在至少一个patch出现“八视图全部FG、镜像平均后BG”；它们也仍有其他native背景视图。因此，不能再用“大家都认为是前景，最终融合错了”解释这批主要损伤。

without_delete有4/2,010个误删位置满足所有raw视图FG但最终BG，其中3个在FP64影子融合仍为BG。确有这种数学现象，但数量很少，不能推广为主要原因。此分支新增假WT中6,389/7,271个位置有Gaussian加权前景多数支持；错误已广泛存在于模型视图响应，而不是融合凭空产生前景。

多数票本身不是可靠性证明，也不等于应该改成多数投票。logits幅度、镜像、patch位置和Gaussian权重均影响最终判断，任何融合修改仍需完整源控制及全部四类评价。

## 舍入误差的规模

下表仅覆盖89,137个观察位置，不能当作整幅图像的误差率。

| 状态 | native对FP64双阶段：四类 / WT变化 | native对FP64滑窗阶段：四类 / WT变化 |
|---|---:|---:|
| Source | 46 / 41 | 44 / 39 |
| full | 41 / 30 | 43 / 31 |
| without_delete | 54 / 34 | 47 / 31 |

full编辑外真实WT误删中仅9/9,548个WT判定因双阶段FP64改变；without_delete为9/2,010个。编辑外新增假WT分别仅1/3,945和6/7,271个改变。舍入确实存在，但不能解释主要错误；本轮也没有检验改变网络内部精度的效果。

## 与训练patch的交叉核对

前轮曾发现full的1,971个编辑外受损位置在所有训练patch中仍为FG。将其与本轮同一状态、同一位置的native记录连接：

| 训练patch中的FG支持 | 体素数 | native raw全FG / 混合 / 全BG | Source加权native支持 | 适应后加权native支持 |
|---|---:|---|---:|---:|
| 所有训练视图FG | 1,971 | 0 / 1,971 / 0 | 75.83% | 43.17% |
| 所有训练视图BG | 2,523 | 0 / 1,944 / 579 | 76.14% | 19.11% |
| 训练视图有分歧 | 5,054 | 0 / 4,972 / 82 | 75.37% | 35.00% |

1,971个位置在native raw视图中全部有分歧，其中902个在所有native镜像平均patch中都为BG。它们不是“所有native视图正确，最终融合才损坏”的位置。训练patch上的保护没有充分转移到真实推断上下文；此处仍未将patch位置与镜像各自作用分开。

组织纠错也不是只在融合mask中出现：full编辑外纠正的29,117个NC位置，native加权NC支持从7.10%升至84.96%，其中10,337个位置所有raw视图都判NC。without_delete对应21,356个位置，支持9.38%→82.31%，全视图NC为5,881个。它表明模型响应改变，仍不证明超过同预算geometry的语义优势。

## 下一项可检验工作

停止把提高融合精度或改变投票作为主要修复。现有证据更支持检验**实际native聚合输出上的软保留目标**，而不是仅在另选的训练patch上约束WT。

可令F(theta,x)表示原native patch/镜像logits的加权聚合，直接在F上使用原四类teacher编辑目标和非编辑位置的WT margin软锚点。这样不硬固定WT/ET、不添加新teacher或改推断规则，而是让适应目标约束真正用于评价的预测函数。源native视图本来就有分歧，不能把所有单视图的类别都当作正确硬标签。
