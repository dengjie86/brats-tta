## 动机与可检验问题

gamma观察不能纠正高置信NC→ED，历史轴置换、裁剪和快照教师也缺少可靠纠错。
本轮检验：保留源预测肿瘤及其邻近MRI，改变远处背景，是否能提供超过源概率排序的纠错位置。
这不是对因果捷径的识别；InstanceNorm统计、感受野内容和分布外伪影同时发生变化。

仍使用单一native IN四分类epoch250，无GLI图像/标签、额外模型或跨病例状态。
四模态native预处理；128³/.5/Gaussian/八镜像；各病例独立计算。
距源argmax WT不超过10mm的四通道值逐值保留，10—20mm平滑过渡。
20mm外两种背景分别为sigma4的病例内masked Gaussian（匹配远处均值/标准差）和远处中位数。
原零值位置保持为零。无WT或某通道远处有效体素不足1000时使用identity，实际12例无回退。

融合平均源及两种新观察的概率。teacher在输入保留区内要求两观察同类、各maxP≥.8、margin≥.2，否则保留source。
所有四类、WT边界和ET均允许变化，没有贴回WT/ET；源完全漏掉且相距超过10mm的病灶不在teacher可恢复范围。
对照匹配同一可编辑范围、每个原类别→目标类别及数量，分别采用源margin排序和固定随机抽样。

## 文献边界

[背景/前景解耦的胰腺CT研究](https://www.sciencedirect.com/science/article/pii/S0893608024002181)
是不同的有监督训练；[Background Conditional Divergence](https://arxiv.org/abs/2506.22505)
依赖弱监督及不同背景资源，都不证明本探针适用于PED。本轮未声称复现或首创。
[PED2023官方论文](https://arxiv.org/html/2407.08855v3)的ED定义涉及周围结构；背景有时有用，去除可能损害判断。
