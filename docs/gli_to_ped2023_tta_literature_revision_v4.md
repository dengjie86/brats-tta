# GLI → PED2023：基于文献的病例独立 TTA 设计

日期：2026-10-06。状态：完成论文、官方实现和损失梯度核查；尚未实施本版患者实验。

本版建议研究**病例内多视图适应中的伪监督粒度**：有细类别证据时监督细类别，只有合并区域证据时只监督合并区域。以 MuVi 的 single-image adaptation 为参照，以医学部分标注分割的 marginal loss 为数学依据。暂不命名新方法，也不声称已经证明创新性或 PED 收益。

## 1. 为什么改变研究问题

当前四分类 native nnU-Net v2、InstanceNorm、Dice+CE、epoch 250，在 99 例 PED2023 上的 WT/TC/ET 平均 Dice 是 89.3334% / 48.8627% / 54.6713%。这是原生预处理、八镜像集成、四分类 argmax 后合并区域的结果。

已经完成的两个实验指出了具体风险：

- MRI 强度/局部统计原型实验的实际 ED 拟合种子逐病例平均纯度仅 18.75%。这些是空间腐蚀种子，不是经过独立验证的高置信种子。它否定的是该种子与拟合规则的可靠性，不能推广成所有 MRI 信息无效。
- 多头适配器实验中，最终头的 NC→ED 错误仅有 1.55% 被至少一个辅助头正确 argmax 为 NC。该实现缺少可用的硬分类纠错候选，且真实适配器未带来有意义的收益。它没有测试 MuVi 的最终头跨轴视图适应。

因此，新的首要问题是：**能否用现有模型和当前病例，识别哪些判断只可信到 WT 或某个类别集合，避免将不可靠的内部类别当作确定答案？** 增加适配器本身不提供这个答案。

这只能减少错误监督。若没有可用的 NC/ET 信息，任何保持这些资源约束的方法都不能保证恢复正确内部分类。

## 2. 文献分别支持什么

| 研究 | 实际依据 | 本设计借鉴 | 适用边界 |
|---|---|---|---|
| [BraTS-PED2023 报告](https://arxiv.org/abs/2305.17033) | 成人模型在儿童肿瘤上可能保持较好的整体分割，却难以区分内部亚区；PED 的 NC 包含非增强、囊性、坏死组织 | 将 WT 与内部类别的监督可靠性分开研究 | 不能据此把肿瘤中心全部标成 NC，或把外围全部标成 ED |
| [MuVi: Single Image Test-Time Adaptation via Multi-View Co-Training](https://arxiv.org/abs/2506.23705)，MICCAI 2025，见官方 README | nnU-Net 对当前一例 MRI 进行轴向视图置换和重叠 patch 学习，每病例重置；报告了 IN 实验 | 使用同一最终头的多视图观察，进行病例内参数更新 | 原实验是乳腺肿瘤二分类；不能直接外推到 PED 四分类；伪标签阈值经过 validation 选择 |
| [Marginal loss and exclusion loss for partially supervised multi-organ segmentation](https://arxiv.org/abs/2007.03868) | 部分真实标注下，合并类别的概率等于各类别概率之和，可用于 CE 和 Dice | 用集合标签替代不可靠的单类别伪标签 | 原研究的集合来自真实标注；本方案的伪集合可能漏掉真类，并无覆盖保证 |
| [Uncertainty-Calibrated Test-Time Model Adaptation without Forgetting](https://arxiv.org/abs/2403.11491) | 研究不同不确定性与可靠性校准，指出不能对所有不确定预测一律强化置信度 | 不把“熵下降”当作内部类别纠正的证据 | 不证明当前模型能够识别 NC/ED 错误，也不直接采用其完整算法 |

其他相关工作用于界定比较范围：

- [TEGDA 官方实现](https://github.com/HiLab-git/TEGDA)研究相关脑肿瘤跨域问题，但所核对实现有 `episodic=False`、feature bank 和 EMA 状态。若作为本项目基线，必须显式逐病例重置，不能把原在线结果当作当前协议结果。
- [VISTA](https://arxiv.org/abs/2605.17433)的公开设定是 online continual、GLI2025→PED2024，且模型和预处理与当前项目不同。可参考可靠性设计，不能作为 PED2023 episodic IN 方案的直接证据。
- [Entropy Minimization without Model Collapse](https://arxiv.org/abs/2606.02339)是医学分类研究，支持检查损失贡献偏置的必要性。不能据此要求 NC/ED/ET 体积均匀，也不引入其跨 batch 统计。

## 3. 资源和协议

只用现有模型包、其中的 plans/模态定义与当前一例 PED2023 的 T1、T1ce、T2、FLAIR。保留原生预处理和类别顺序 `BG, NC, ED, ET`。

不访问 GLI 图像或标签，不建立源原型，不重新训练源模型，不引入外部预训练教师。每病例从相同 checkpoint 开始，重新建立 optimizer，病例结束丢弃全部临时状态。无跨病例 EMA、类别频率、缓存原型或模型更新。

标签只在预测固定后评价。既有 99 例的诊断已经影响方案设计，后续在这些病例上的结果均属于开发证据；重新切分这些病例不能使其成为完全未见的独立验证。

## 4. 一个具体、可实现的候选版本

### 4.1 用同一最终头产生三个视图

冻结源模型，分别对原空间排列及两个循环轴置换进行预测。所有模态同步变换，输出逆变换回同一物理位置。采用相同的 sliding-window 覆盖和 Gaussian 融合。只使用最终分割头，不使用深监督辅助头。

这里的三个视图是同一 3D MRI 的空间轴排列，不是新增扫描序列，也不是三个独立专家。它利用网络可能存在的方向敏感性；方向变换也可能制造额外分布偏移，所以要先测其候选质量。必须核查体素间距、patch 维度和坐标往返映射，不能只交换数组后忽略几何。

保存三份对齐概率 `q_j(v)`，适应过程中固定。不要利用适应后的预测不断改写自己的监督目标。

### 4.2 生成有明确规则的候选类别集合

先固定一个可证伪的起点，避免事后凭结果调整规则：

1. 每个视图、每个体素按概率降序取最小类别集合 `A_j(v)`，使累计概率至少达到 `0.9`；并列概率按固定类别 ID 排序。
2. 取并集 `U(v) = union_j A_j(v)`，保留不同视图支持的候选。
3. 如果 `U` 同时包含 BG 和前景，首版令 `S(v)` 为全部四类，即跳过该体素的直接伪监督；如果只有 BG，保留 `{BG}`。
4. 若 `U` 只含前景，基础版直接令 `S=U`。
5. 单独检验一个针对当前错误模式的修改：前景集合中只要有 ED，就额外允许 NC，即 `S=U union {NC}`。例如一致预测 ED 也降为 `{NC,ED}`。

`0.9` 是预先固定的工程起点，不是校准置信度，更不是“包含真类的概率为 90%”。多视图一致也不是正确性证明。

第 5 步是本项目诊断启发的**非对称松弛假设**，并非现有论文结论或普适医学规则。它正面处理“所有视图一致但都把 NC 判成 ED”的情况；只对不一致位置降权会漏掉这种错误。

代价也明确：该修改取消了 ED 的单类正监督，可能使真实 ED 被错误扩张的 NC 侵占。因此必须与不松弛的版本配对比较，不能仅凭 TC 召回上升接受它。

得到的典型监督含义如下：

| `S(v)` | 当前允许的判断 | 不应强迫模型回答的判断 |
|---|---|---|
| `{BG}`、`{NC}`、`{ET}` | 相应细类别候选 | 候选正确性仍需事后测量 |
| `{NC,ET}` | 属于 TC | NC 与 ET 的细分 |
| `{NC,ED}` | 属于非增强肿瘤组织候选集合 | NC 与 ED 的细分，因此此处不能生成硬 TC 监督 |
| `{NC,ED,ET}` | 属于 WT | TC、ET 的内部归属 |
| 全部四类 | 信息不足 | 跳过直接伪监督 |

集合中没有某一类不等于该类在病例中真实不存在。尤其要测被错误排除的 ET 和被背景一致漏掉的肿瘤。

### 4.3 在可信粒度上计算损失

设学生输出四分类 Softmax 概率为 `p_theta(v)`，集合伪监督为：

\[
L_{set}(v)=-\log\left(\sum_{c\in S(v)}p_{\theta,c}(v)\right).
\]

单类集合退化为普通 CE；`{NC,ED}` 只要求两类概率之和增大；四类集合的损失和梯度均为零，实际实现直接跳过。

例如 `p=[0.05,0.10,0.80,0.05]`，硬 ED 监督采用 `-log(0.80)`，而 `{NC,ED}` 采用 `-log(0.90)`。对 NC logit，前者梯度为 `+0.10`，后者为 `-0.01111`。在把 logit 当独立变量的梯度下降中，前者压低 NC，后者不再把 NC 当作被排除的类别。

**这不等于后者会纠正成 NC。** 在同一例子中，集合损失对 ED logit 的梯度为 `-0.08889`，其上升仍可能比 NC 更快；实际网络还有共享参数耦合。因此不能声称它保持 NC/ED 比例、保证 TC 增长，或凭损失下降证明纠错。

视图一致性也必须采用同一粒度。对每个体素定义概率分组：把 `S(v)` 合为一组，其余类别各为一组，记聚合操作为 `B_S`。在对齐后的三个视图间使用：

\[
L_{view}(v)=JS\big(B_{S(v)}p_1(v),B_{S(v)}p_2(v),B_{S(v)}p_3(v)\big).
\]

例如 `S={NC,ED}`，比较的是 `[p_BG,p_NC+p_ED,p_ET]`，不能同时再加一个强迫 NC/ED 相等的四分类 consistency 或四分类伪 Dice。否则会把刚刚放宽的错误答案重新引入。

首版只用 `L_set + L_view`，两项分别对有效体素和视图取均值后等权。全类集合不参与任一项。不加特征原型、模态删除、形态学扩张或全局最小熵。候选组的有效体素数和梯度贡献需要记录；首版不以均匀类别体积为目标。

### 4.4 更新什么、如何输出

不加额外适配器。第一轮机制比较更新现有 **decoder 的卷积、IN affine 和最终分割头参数**，encoder 冻结，辅助分割头不参与损失。每个病例重新加载源参数并新建 optimizer。

这是减少显存和缩小试验范围的工程选择，并非 MuVi 原版参数设置。MuVi 原文更新所有模型参数；如果后续试验扩大到全模型，各损失对照必须同步扩大，不能把参数范围收益归给集合监督。

候选初始预算：`patch=128^3`、`batch=1`、AMP、SGD `lr=1e-4`、无 momentum/weight decay、20 个 optimizer steps。这是待预注册的 pilot 配置，不是论文验证过的 PED 最优值。每步取一个确定性 patch 及三视图，三图对应同一集合目标。所有对照共享 patch 顺序、参数范围、预算和最终推理方式。

先做一个病例的前后向显存与坐标检查。8 GiB 上三视图计算图能否容纳尚未验证；若需 activation checkpointing，应保持数学目标和有效更新步数，不静默改 patch 或损失。真实数据运行前冻结最终配置，不能用评价标签挑学习率或停止点。

更新后按现有完整体积八镜像推理、四分类 argmax，再合并得到 `WT={NC,ED,ET}`、`TC={NC,ET}`、`ET={ET}`。这种合并天然满足区域包含关系，但不保证任何区域的 Dice 不下降。

若有效集合全为空，或整例没有 NC/ET 单类候选，首轮默认保留源预测并记录回退原因。该回退只是一条可实现的规则：它不能证明源预测更好，也不是自动发现真实缺失类别。少量候选是否足够需要另行报告。

## 5. 改善可能来自哪里，不能来自哪里

可能的纠错信息仍然来自已有网络：同一最终头在不同空间视图上的互补输出，以及病例内相对可靠的 NC/ET 区域。共享 decoder 的更新可能把这些局部判别推广到其他区域。集合监督用于减少推广时来自错误 ED 伪标签的反向阻力。

这包含两个尚待验证的假设：多视图确实有可利用的细类别信息；放宽 ED 后，正确 NC/ET 信息的传播超过误扩张造成的损害。两者缺一不可。

- WT：保留有前景共识的集合监督，但边界或共同漏检仍可能错误。
- TC：只在 `{NC}`、`{ET}`、`{NC,ET}` 等候选上获得相应正信息；`{NC,ED}` 本身不能告诉模型哪边是 TC。
- ET：用有支持的 ET 候选学习，同时检查错误负监督和假阳性；不能强迫每病例都有 ET。

如果源模型在各视图中都稳定地分错内部类别，且病例内没有可靠锚点，该方案不能从合并损失中创造新的类别知识。届时应停止这条路线，而不是靠增大更新步数或换适配器掩盖信号不足。

## 6. 先检验机制，再决定是否做完整比较

第一阶段只生成并固定候选，随后才读取标签评价，不先跑大规模适应：

1. 分别测三视图最终头、平均融合及原生八镜像的质量，量化 NC→ED 错误中的正确 NC 候选覆盖；不能把覆盖率当最终可实现收益。
2. 测候选集合包含真类的比例，同时报告集合大小、单类候选纯度、病例覆盖和被跳过比例。四类集合的 100% 覆盖没有判别意义。
3. 对一致 ED、分歧 ED、ET 漏检/假阳性分别分析；第 5 步加入 NC 后增加多少正确候选，也保留多少真实 ED 歧义。
4. 若视图互补性仍接近此前辅助头的低覆盖，且细类候选不可靠，则不推进长适应实验。

第二阶段做小规模、相同预算的配对比较：

| 对照 | 目的 |
|---|---|
| 冻结源模型，原生八镜像 | 当前实际基线 |
| 冻结模型，多视图直接融合 | 分离额外推理视图与梯度适应的效果 |
| 同视图、同 decoder 更新，固定四分类硬伪标签 | 多视图自训练参照；明确称 MuVi-inspired 四分类变体 |
| 只保留单类候选，丢弃歧义体素 | 检查收益是否仅来自减少错误监督量 |
| 使用候选集合，不额外放宽 ED | 检查合并监督本身 |
| 候选集合＋ED 允许 NC | 检查本项目的定向松弛假设 |

集合版需要同步聚合 consistency；另做一次“已合并监督但仍用四类 consistency”的消融，可检验细类信息是否通过第二项重新锁死。不能把这些变体叫作未经修改的 MuVi 复现。

同时报告 WT/TC/ET Dice、HD95、precision/recall、纠正/破坏体素数、病例胜负、实际预测改变量和回退率，附配对 bootstrap 区间。没有真实适应收益、只比一个更差变体好或几乎不改预测，都不算支持新方法。

阶段二的推进标准应在预测前固定：TC 需有可重复增益，并同时检查 WT/ET 退化。候选非劣容忍量可设每区 0.5 pp，但这是研究者需预注册的实用阈值，不是医学标准；小 pilot 区间较宽时只能判证据不足，不能判已经安全。完整结论还需要未参与方案选择的验证数据。

## 7. 官方代码核查和本次验证记录

核对 MuVi 官方代码 commit `f19e4ec474a7d6e49ade60f2a6c2a1cfe4110643`：

- [trainer](https://github.com/smriti-joshi/muvi/blob/f19e4ec474a7d6e49ade60f2a6c2a1cfe4110643/scripts/test_time_training_methods/muvi/muvi_trainer.py) 的 `_get_pseudolabel` 用 `(sum(threshed) > 0)` 合并预测，输出二值肿瘤标签；不能直接代表四个类别。

- 按原生 `[N,C,D,H,W]` 输出，consistency 部分的 `argmax(output, dim=0)` 操作的是 batch 维；需要在兼容实现中检查并使用类别维。不能把未核验的直接运行当作论文算法复现。
- [配置](https://github.com/smriti-joshi/muvi/blob/f19e4ec474a7d6e49ade60f2a6c2a1cfe4110643/scripts/test_time_training_methods/muvi/config.yaml) 使用 SGD `lr=1e-3`、momentum `0.99`、weight decay `3e-5`，轴向/其他视图 entropy 阈值 `0.4/0.2`。本方案没有把这些经其验证选择的阈值宣称为 PED 的已验证设置。

核对 marginal loss 原文第 3.2 节：合并概率为相关类别概率之和；其监督集合来自部分真实标注。本版没有移植 exclusion loss，也不声称部分真实标注与伪集合可靠性相同。
